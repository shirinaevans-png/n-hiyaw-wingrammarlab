# nêhiyawêwin Grammar Lab

Starter GitHub Pages project for a linguistics final project.

## What is included
- Animacy Challenge using NA / NI nouns from the uploaded workbook
- Verb Detective using the workbook's VAI, VTA, VTI and VII labels
- Cree-English Word Match
- A cautious sentence-builder prototype using the verified `mîcisow` VAI paradigm
- Searchable vocabulary explorer using the full Master Vocabulary sheet

## Run it on your computer
Open `index.html` in a browser.

## Put it on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and `data.js` to the repository root.
3. Open Settings > Pages.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Choose the `main` branch and `/ (root)`, then Save.
6. GitHub will provide the public Pages address after deployment.

## Important linguistic design note
This version deliberately does not automatically conjugate every verb. The workbook notes that VAI, VTI, VTA and VII do not share one interchangeable ending system, and some stem alternations must be verified. Future modules should add verified paradigms rather than generate unsupported forms.
